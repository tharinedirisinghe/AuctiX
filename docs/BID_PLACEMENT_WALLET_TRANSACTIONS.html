🔍 System Overview

The AuctiX auction system implements a sophisticated bid placement and wallet transaction mechanism that ensures complete financial safety while providing seamless user experience. The system handles all aspects of auction bidding, from fund management to real-time notifications.

Key Features:

  • Atomic Transactions: All operations are database-transaction safe
  • Fund Protection: Only highest bidder has frozen funds at any time
  • Real-time Updates: WebSocket notifications for immediate feedback
  • Comprehensive Error Handling: Multiple validation layers with rollback
  • Audit Trail: Complete logging of all financial operations

💰 Wallet Transaction Types

📈 CREDIT TRANSACTIONS

  • CREDITED - Wallet recharge
    • User adds money via payment gateway
    • Increases available balance
    • Notification: "Wallet Recharged Successfully"
    • Transaction fee may apply
  • UNFREEZED - Funds returned
    • When outbid by another user
    • When auction is cancelled/deleted
    • When bid placement fails after freezing
    • Returns funds to available balance

📉 DEBIT TRANSACTIONS

  • DEBITED - Withdrawal
    • User withdraws to bank account
    • Decreases available balance
    • Requires bank details verification
    • Processing time: 1-3 business days
  • COMPLETED - Auction payment
    • Winning bidder's final payment
    • Funds transferred from frozen to seller
    • No return to bidder's available balance
    • Triggers delivery creation

🔒 FREEZE TRANSACTIONS

  • FREEZED - Bid placement
    • Funds locked during active bidding
    • Removed from available balance
    • Added to frozen balance
    • Only highest bidder has frozen funds
    • Automatically unfrozen when outbid

🎭 Special Scenarios

🔥 Auction Deletion with Bids

Trigger: Seller deletes auction that has active bids

Process Flow:

  1. Validation: Check if deletion allowed (not within 1 hour of end time)
  2. Find Highest Bidder: Only they have frozen funds
  3. Unfreeze Funds: UNFREEZED transaction created
  4. Notification: "Auction Cancelled - Funds Refunded" sent to bidder
  5. Watchlist Notification: All watchers informed of cancellation
  6. Auction Status: Marked as deleted with reason logged

Code Location: AuctionService.java:457 → BidService.java:443

Result: 100% fund safety - All bid amounts returned atomically

⚡ Concurrent Bidding

Scenario: Multiple users bid simultaneously on the same auction

System Behavior:

  • 🥇 Database Ordering: First transaction to commit wins
  • 🥈 Validation Failure: Later bids fail with "amount too low" error
  • 🔄 User Experience: Failed bidders can retry with updated minimum
  • 💰 Fund Safety: Failed bids never freeze money
  • 📡 Real-time Updates: WebSocket notifies all clients of successful bid

Technical Implementation: Database constraints + optimistic locking

🛡️ System Failure Recovery

Scenario: System crash during bid placement or fund operations

Recovery Mechanisms:

  • 🔄 @Transactional Rollback: All database changes reverted

  • 📝 Audit Logging: Failed operations logged for investigation
  • 🔔 User Notification: Clear error messages with retry options
  • ⚡ Auto-Recovery: Users can immediately retry operation

🔐 Security Measures

Authentication & Authorization

  • JWT Token Validation: All requests require valid authentication
  • Role-Based Access: Only BIDDER role can place bids
  • Self-Bidding Prevention: Sellers cannot bid on their own auctions
  • Session Management: Secure token handling with expiration

Financial Security

  • Fund Protection: Atomic transactions ensure no money is lost
  • Double Validation: Both frontend and backend validate all operations
  • Audit Logging: All financial transactions are logged with timestamps
  • Balance Verification: Continuous balance consistency checks

Business Logic Security

  • Bid Amount Limits: Maximum 100M LKR to prevent overflow attacks
  • Timing Validation: Strict auction start/end time enforcement
  • Increment Enforcement: Tiered minimum bid increments
  • Deletion Restrictions: Cannot delete auctions within 1 hour of end
