Wallet Analysis Logic

Comprehensive Financial Intelligence System

System Overview

The WalletAnalytics component provides comprehensive financial analysis and visualization for user wallet transactions. It processes transaction data to generate meaningful insights, trends, and visual representations that help users understand their financial patterns and make informed decisions.

Core Financial Metrics

Total Credits
Purpose: Tracks all incoming money (income/deposits) to monitor cash inflow patterns
Calculation: Sum of all CREDITED or UNFREEZED transactions
totalCredits = sum(CREDITED + UNFREEZED amounts)

Business Value: Essential for budgeting, income tracking, and financial planning decisions.

Total Debits
Purpose: Monitors all outgoing money (expenses/withdrawals) for spending analysis
Calculation: Sum of all DEBITED or COMPLETED transactions
totalDebits = sum(DEBITED + COMPLETED amounts)

Business Value: Critical for expense management and identifying cost control opportunities.

Average Transaction
Purpose: Reveals typical transaction size to understand spending behavior patterns
Calculation: Total amount divided by transaction count
avgAmount = totalAmount / transactionCount

Business Value: Identifies spending habits - many small vs few large transactions.

Transaction Count
Purpose: Measures user activity level and platform engagement
Calculation: Simple count of all transactions
count = transactions.length

Business Value: Indicates user engagement for retention analysis and activity scoring.

Chart Visualizations & Data Processing

Balance History

Purpose: Visualizes wallet balance progression over time
Processing Steps:
  1. Sort transactions chronologically
  2. Calculate running balance for each transaction
  3. Add amount for CREDITED/UNFREEZED
  4. Subtract amount for DEBITED/COMPLETED
  5. Plot as smooth area chart

Business Value: Shows wealth accumulation trends and financial growth patterns.

Transaction Distribution

Purpose: Shows proportion of different transaction types
Processing Steps:
  1. Group transactions by status type
  2. Count occurrences and sum amounts
  3. Calculate percentage distribution
  4. Render as color-coded pie segments

Weekly Activity

Purpose: Displays recent 7-day transaction activity patterns
Processing Steps:
  1. Generate array for last 7 days
  2. Filter transactions for each day
  3. Calculate daily credits and debits
  4. Display as comparative bar chart

Business Value: Identifies daily spending patterns and weekly financial behavior.

Monthly Overview

Purpose: Shows monthly credit/debit trends over time
Processing Steps:
  1. Group transactions by month-year
  2. Sum credits and debits for each month
  3. Plot as dual-line graph
  4. Show trend progression over months

Business Value: Reveals long-term financial trends and seasonal patterns.

Advanced Analytics & Insights

Financial Analysis Metrics

Net Cash Flow
Purpose: Determines if user is gaining or losing money overall
netCashFlow = totalCredits - totalDebits
Balance Utilization
Purpose: Shows percentage of total balance available vs frozen
utilization = (currentBalance / totalBalance) × 100
Credit to Debit Ratio
Purpose: Measures income vs expense ratio for financial health assessment
ratio = totalCredits ÷ totalDebits

Activity Insights

Daily Average Spending
Purpose: Shows typical daily expense amount for budgeting
dailyAvg = totalDebits ÷ daysSinceFirstTransaction
Transaction Frequency
Purpose: Measures how often user makes transactions
frequency = transactionCount ÷ daysSinceFirst
Most Active Type
Purpose: Identifies predominant transaction behavior pattern
mostActive = max(transactionTypes.count)

Trend Analysis

Balance Growth Rate
Purpose: Shows financial growth rate as percentage
growth = ((netFlow ÷ totalCredits) × 100)%
Spending Consistency
Purpose: Measures monthly spending pattern consistency
Uses variance analysis: High/Medium/Low consistency rating
Balance Efficiency
Purpose: Shows how efficiently available balance is utilized
efficiency = (currentBalance ÷ totalBalance) × 100
